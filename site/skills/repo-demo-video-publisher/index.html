This package is a single SKILL.md with no bundled resources.

Why

README video work has a habit of leaving behind junk, accidental private data, and a thumbnail nobody checked.

How

Start only from an approved direction, work in scratch, inspect the first frames and audio, get a second approval before upload, then make the README-only change and guard the diff.

Related

Begin with Repo Demo Video Director and use Browser Hand for the authenticated upload path.
