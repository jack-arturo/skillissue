# Refinement patterns

- `composition-drift`: put an unambiguous camera-position clause first; match `--ar` to the desired frame.
- `subject-drift`: move the literal subject to the start and add a material, era, or functional anchor.
- `style-drift`: replace vague mood words with observable lighting, material, and era cues; exclude the recurring adjacent style.
- `palette-drift`: state the dominant colors early and exclude the unwanted family.
- `negative-violation`: turn the violated constraint into a positive physical description as well as a `--no` item.
- `text-gibberish`: shorten the requested text and plan a post-production text layer when exact typography matters.
- `rate-limit`: stop and ask the user before retrying.

Apply only the dominant failure mode after a round; piling on every remedy muddies the next result.
