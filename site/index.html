agents

Memory, orchestration, research. What the agent does next.

  • long-haul-parallel-repairstart Agents would either under-delegate or fan out without authorization. This skill is the contract for when "work for hours" is real.
  • skill-authorstart Half-finished SKILL.md files were rotting in chat. This is the admission checklist before something enters the vault.
  • automem Memory only works if every agent uses the same ritual. This skill is that ritual for Grok/Claude/Codex hosts.
  • autovault-skill Agents kept looking for MCP when the skill was already symlinked. This meta-skill explains the model.
  • entity-dossier Pre-meeting context kept dying with the chat. The dossier in AutoMem is the deliverable.

cloudflare

Deploys, lead capture, DNS. The wrangler scars, written down once.

  • cloudflare-lead-capturestart Hat Trick / waitlist work kept being rewritten. Packaged as scaffold + doctor + setup.
  • cloudflare-opsstart Every AutoHub-adjacent deploy was re-discovering the same wrangler gotchas. This skill is the operator runbook: one canonical deploy path, preview D1 isolation, no split-brain…
  • cloudflare-commerce-deploy Commerce launches need DNS, secrets, and preview/prod isolation — not ad-hoc wrangler folklore.
  • cloudflare-emdash-cms-deploy Pages-shaped deploys were serving raw source after Astro 6. This skill owns the Workers recipe and binding gotchas.
  • phala-gpu-tee-deploy A guarded runbook for placing a GPU workload on a confidential Phala deployment and proving what actually ran.
  • pirsch-analytics-bootstrap Analytics installs were inconsistent and sometimes created domains without asking.

git

Review loops and commit identity. PRs that finish.

  • babysitstart PR review loops were eating whole sessions. Babysit is the exclusive-label workflow: active, waiting-codex, waiting-ci, blocked, ready.
  • commit-message Commit messages were either empty or novels. This drafts from the staged diff.
  • github-agent-identity One GitHub App per coding agent, so Claude Code and Codex commit, comment and open PRs as themselves. Your name stays on the merge button.

browser

  • browser-handstart Drive your real logged-in Chrome from an agent — extension bridge, no remote debugging port on the default profile, background-first so focus stays with you.

ops

Boards, Home Assistant, inboxes. Machines that are not a repo.

  • resend-cli Email setup needed a vendor CLI skill with non-interactive agent flags.
  • triage-autohub-runtime Retry storms looked like many bugs. This skill separates root cause from cascade.
